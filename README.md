# 🧠 Deep Learning from Scratch — Vizuara-Based Projects

This repository is inspired by the [Vizuara Deep Learning from Scratch](https://youtube.com/playlist?list=PLPTV0NXA_ZSj6tNyn_UadmUeU3Q3oR-hu&si=Rta-BAy9yLHhDfwl) playlist. 
It walks through the core components of building a neural network from the ground up, without relying on high-level libraries like TensorFlow or PyTorch.

## 📚 Course Structure

The learning journey is divided into the following modules:

### 1. Layers, Activation Functions & Loss Functions
- Custom implementation of dense layers
- Activation functions: ReLU, Sigmoid, Softmax
- Loss functions: Mean Squared Error (MSE), Cross-Entropy

### 2. Optimizers
- Gradient Descent
- Momentum
- Adam

### 3. Training the Neural Network
- Forward and backward propagation
- Weight updates
- Mini-batch training

### 4. Testing the Neural Network
- Evaluation metrics
- Accuracy and loss tracking
- Generalization checks

### 5. Projects
- Application of learned concepts to real-world datasets

---

## 🚀 Projects

### 🧵 Project 1: Fashion MNIST Classification
- **Objective**: Classify clothing items into categories such as T-shirt, Trouser, Sneaker, etc.
- **Dataset**: Fashion MNIST
- **Model**: Multi-layer neural network with Softmax output
- **Loss Function**: Cross-Entropy

### 🏠 Project 2: California Housing Price Prediction
- **Objective**: Predict median house prices based on location and features
- **Dataset**: California Housing Dataset from Scikit-learn
- **Model**: Regression neural network
- **Loss Function**: Mean Squared Error (MSE)
